# TCP 多连接交付记录

用户于2026年11月10日确认每条转发支持16个并发连接，用于多个网页和客户端。本批保留固定目标、会话授权、目标白名单、背压和流量限制。

## 实现

- 公共协议模块统一定义每条16个、MCP和Agent进程各32个、Relay进程128个活动连接上限。
- MCP和Agent在同一状态锁内统计并保留连接名额，目标连接中的请求也占用名额。连接结束或转发关闭时释放。
- Relay同时检查单条、Controller、Agent及进程总数。配额耗尽只拒绝新连接，保留当前监听和已建立连接。
- MCP状态说明使用共享常量生成，明确本次拒绝和总配额。
