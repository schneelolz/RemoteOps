# 串口显示与原生资源站验证记录

日期：2026-11-05。本文记录 R02 与本轮补充的原生 R01 设置入口；整体进度以《RemoteOps改进实施与交接》为准。

## 修改范围

- `apps/remoteops-agent/src/operation_log.rs`：完整行脱敏前判定可聚合性，串口显示旁路生成稳定记录标识及包含首次输出的累计次数。UTF-8、CRLF 拆分继续沿用现有缓冲；空行只作为内部连续性边界，不改变远程返回行。不同正文、来源、会话、资源或连接代次结束连续段；脱敏、截断和控制内容不参与聚合。关闭时冲刷的部分行独立显示。
- `apps/remoteops-agent/src/observation.rs`：在有界队列淘汰之前按同代次、同显示类型和稳定标识替换累计更新，替换本身不增加省略计数。日志与观察终端各保留自己的最新累计值。
- `apps/remoteops-agent/src/lib.rs`：本地日志重复元数据和本地累计输出事件；未添加或更改远程输出线协议。`AgentOperationLog` 字面量同步补充可选元数据，包括 GUI、activity 和 service 测试。
- `crates/remoteops-agent-desktop-host/src/lib.rs`、`runtime.rs`：日志与观察记录传递稳定标识，显示 `× N`；日志历史按标识更新，未读数不因累计更新重复增加。队列提示使用“中间显示记录已省略”。
- `apps/remoteops-agent-gui/src/lib.rs`、`activity.rs`：日志抽屉及活动摘要更新同一显示记录。摘要的计数独立于正文截断；后者由语言与审查代理补充复核。
- `apps/remoteops-agent-native-prototype/src/style_preview/observer_data.rs`：分类模型按标识更新并继续执行历史条数、UTF-16 容量限制；暂停由已有窗口机制保持，恢复时读取最新累计值。
- `apps/remoteops-agent-native-prototype/src/model.rs`、`win32.rs`：旧原生观察模型更新记录并增加渲染修订号，使暂停或返回最新后能刷新已有行。
- `apps/remoteops-agent-native-prototype/src/style_preview.rs`、`style_preview/business.rs`、`win32/product_ui.rs`：原生样式“连接设置”和旧原生“偏好设置”提供可选清单 URL、HTTPS 来源白名单、停止连接与保存资源设置入口；白名单以分号分隔。保留语言与外观切换前的输入草稿。

## 原生资源配置行为

共享 `SaveResourceTools` 动作先检查后台运行和证书确认状态；必须先停止再更改配置。清单留空保存为关闭，来源白名单经共享资源配置校验，成功后原子保存，仅下次连接生效；窗口不自行下载或执行资源。停止连接同时清除未完成的证书候选，防止旧候选阻塞保存。

构建脚本 `Build-NativeStyledProduct.ps1`、`Build-NativeStylePreview.ps1` 从 `cargo metadata` 读取独立原生包版本并核对生成物。截图脚本 `Capture-NativeStyleWindows.ps1` 接受精确 `ExpectedVersion`（本候选默认 `0.5.0`）；`Test-NativeStylePreview.ps1` 关于页断言改用传入版本。
