## 后续界面工作的方向

- 候选只保留 Rust + Win32 与 Rust + Slint，共用 Rust 业务核心，按同功能、同构建和分发内容、同机器与测试条件比较。尚未决定正式迁移，不仅凭 EXE 体积选型。
- 保留 GUI 双击启动和 CLI；目标为 Windows 10/11、Windows Server 2016 及以上。目标范围不等于这些系统均已通过兼容性测试。
- Windows 7、Server 2008 R2/2012 路线冻结；确有需求再评估精简 CLI。普通 Server 2008 不纳入。
- 过程窗口用于展示实际命令与回显，不自动扩大成完整终端模拟器；交互输入和终端控制序列另行确定。
- 设计技能用于方向、资料和审查，按任务选主流程，不自动安装，不把网页技能适用性当作 Win32/Slint 的实现质量保证。
