# 工具中心布局与详情展示交付

2026-11-07 已将管理前端 `0.1.1` 部署到生产。页面使用既有 Vue 3、TypeScript、Vite 和 Vue Router 工程，本批完成前端独立升级。

## 页面调整

- 点击工具中心父菜单或访问 `/tools` 时进入“全局设置”。明确指定的子页面、旧书签、刷新和浏览器前进后退均保持目标语义。
- 桌面节点同步页通过弹性布局使用剩余高度，列表内部滚动，表头和底部分页固定。手机及低高度窗口使用自然页面滚动，保持操作区可达。已应用配置字段改为“已应用目录版本”。
- 工具列表行垂直居中，按用途、版本平台、校验、测试、开关和操作分配列宽，长用途收为两行。工具列表默认每页 20 项，可选 50、100 项，筛选变化后回到第一页。
- 工具详情进入独立弹窗，划分使用指南、版本与平台包、测试记录三个页签。多版本通过选择器切换，桌面最大宽度 1120px，手机接近全屏，内容区域独立滚动。
- 详情转编辑或测试登记时替换当前弹窗。取消后恢复详情页签与版本，保存后重新读取工具资料。最终关闭详情时恢复原按钮焦点，同时保留列表筛选、页码和滚动位置。
- 新增弹窗切换期间的触发按钮管理，并修正旧书签在路由初始化阶段的转换顺序。

版本记录更新至 `relay-admin/package.json` 与锁文件的 `0.1.1`。部署模板默认前端镜像同步提升，生产升级由 `scripts/update-relay-admin.py` 完成。新增 `scripts/test-tools-layout-browser.cjs`，接入既有真实隔离 Relay 浏览器回归。

## 部署与备份

生产前端镜像为 `remoteops-relay-admin:0.1.1-20261107`，容器健康，重启计数为 0。后端当前版本为 `0.2.0-preview.17`，部署前后容器标识、镜像、启动时间和重启计数逐项匹配。

备份目录为 `/opt/remoteops/backups/remoteops-before-admin011-20261107-verified`，包含旧 Compose、环境文件、状态文件、三个 SQLite 数据库的在线备份、旧镜像记录和回退脚本。配置及备份文件使用受限权限，旧镜像保留。

服务器原 Python 3.6.8 与 SQLite 3.26.0 在初次备份阶段发生版本限制，流程在切换前停止。修正后使用固定摘要的 Python 3.13 Alpine 临时容器执行 SQLite 在线备份，源卷只读挂载，目标目录按数据卷用户授权，三个备份均通过完整性检查。原失败备份目录保留供追溯。

实际切换使用 `docker compose up -d --no-build --no-deps --force-recreate remoteops-relay-admin`。核验结果包含 15 份静态文件摘要一致、9 个认证只读管理 API 通过、未认证请求返回 401、工具目录摘要一致，以及公网业务 TLS 的系统信任、主机名与 TLSv1.3 验证通过。
