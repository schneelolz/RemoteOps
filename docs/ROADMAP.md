# 路线图

路线图区分“当前要做”和“未来参考”，不把尚未验证的想法描述成已承诺功能。

## 阶段 0：公开 Technical Preview

状态：当前阶段。

- 固定产品定位为面向 AI Agent 的受控远程操作层。
- 完成自托管 Relay、Windows Agent、Controller CLI/GUI 和 Codex MCP 的干净安装说明。
- 以当前 `0.2.0-preview.5` 源码继续完成公开预览后续门禁；首个公开产物基线仍为 `0.2.0-preview.5`，不混淆源码候选版本和已发布版本。
- 完成低权限 Windows、Agent Service、真实串口和代码签名门禁。
- 用三个公开演示证明价值：Windows 诊断、交换机串口诊断、重启后恢复。
- 首版不提供运行时能力开关；Agent 启动后默认开放当前环境中实际可用的能力，权限模式、敏感操作审批和审计边界继续生效。
- 普通 MCP 默认逐项确认，允许用户按 Agent 临时开启完全控制；授权仅驻留 MCP 内存并以一小时空闲 TTL 滑动续期。独立 Human Controller 保留为后续 Controller GUI、多观察者和人工接管能力，不作为首版 MCP 必需组件。
- Agent 默认首次接入只填写 Relay 地址并显示九位控制码，不要求普通用户预先取得额外入网码或部署级 Token；公网 CA 零配置，未知自签名证书由 GUI 展示指纹并经用户核对后固定信任。

## 阶段 1：现场可靠性

状态：发布后按真实反馈安排。

- 按真实部署需求评估可选的 Relay 管理 Web。它只服务部署管理员，可配置开放入网或邀请码/准入密码策略，并提供签发、轮换、吊销、有效期、使用次数、限流和审计；管理入口必须独立认证并保护凭据，不作为普通 Agent 的默认依赖，也不作为 Technical Preview 首发门禁。
- 完善长时间断线、重连、停止、取消和任务恢复。
- 补充管理员 Service、低权限账户和杀毒软件环境的兼容性记录。
- 完善串口设备枚举、拔插、华为 VRP 只读查询和写入审批回归。
- 增加发布包签名、升级和回滚说明。
- 按真实反馈评估 Agent 运行时能力开关，支持命令诊断、文件传输、SSH 设备和串口设备逐项控制；实现时必须同时覆盖 Agent 执行拦截、活动会话终止、Relay/Controller 状态同步、MCP 全工具校验、明确错误提示和端到端测试，不能只做 GUI 状态切换。
- 保持 Windows-first，避免在没有真实需求前扩展平台数量。

## 阶段 2：图形化 Provider 接入

状态：未来参考，第一阶段不实现。

- 允许 RemoteOps MCP 与现有图形 MCP 并列接入，先验证真实任务是否需要画面和输入。
- 定义独立 Visual Provider 能力发现、截图、输入、会话停止和人工接管接口。
- 通过外部进程、MCP 或稳定协议隔离第三方图形方案，不把远控底层代码复制进核心。
- 统一命令、文件、设备和图形动作的权限、Owner、任务状态和审计。
- 图形能力默认关闭，明确区分观察、点击、键盘输入和高风险 UI 操作。

候选方案和许可证记录见 [`VISUAL_PROVIDER_RESEARCH.md`](VISUAL_PROVIDER_RESEARCH.md)。采用前必须重新核对上游仓库和依赖许可证。

## 阶段 3：跨平台被控端

状态：未来参考。

- 在 Windows 版本稳定且存在真实用户需求后，再评估 Linux 和 macOS Agent。
- 保持核心协议、权限和审计跨平台；把 Shell、串口、服务和系统能力放进平台适配层。
- 不为跨平台而提前牺牲 Windows 现场安装和故障排查体验。

## 阶段 4：任务编排与生态

状态：未来参考。

- 支持可恢复的多步骤诊断任务，但每一步都必须保留可取消、可审计和人工接管边界。
- 提供 Provider 接口和示例，让 AI 服务、图形工具和设备工具保持可替换。
- CoderPlant 只作为可选的 AI Provider 或赞助入口，不改变 RemoteOps 的独立性。

## 暂不做的方向

- 自行实现远程桌面视频编码、WebRTC、RDP/VNC 协议或通用 UI 自动化引擎。
- 维护者运营公共 Relay、代理池或任意网络隧道。
- 在没有真实客户验证前建设复杂的多租户 SaaS 控制面。

## 停止条件

如果公开后连续一段时间没有外部用户完成核心流程，应优先修复定位、安装门槛和演示质量，暂停图形化、跨平台和大型架构扩展，而不是继续堆功能。
