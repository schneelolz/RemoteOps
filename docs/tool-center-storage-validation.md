# 工具中心存储与管理契约验证

验证日期：2026-11-05。范围为本地工作区 `crates/remoteops-tool-center`，没有部署、上传到生产中继、替换运行组件或执行 Git 写操作。

## 实现边界

独立 `tools.sqlite3` 保存工具资料、包校验事实、测试记录、管理幂等回执和审计。ZIP 保存在 `packages/<sha256>.zip`，不写入数据库。外链仅临时下载并验证，结束后删除临时 ZIP；签名 URL 只进入内部包来源记录和发给已认证 Agent 的实际目录，普通列表、回执及类型的 Debug 输出去掉查询参数。

新增工具及全局开关默认关闭。文件校验、平台测试和是否启用是独立事实。登记输入不能伪造 `file_verified`、平台 `passed` 或测试操作者；Windows 通过记录必须包含实际 build，需要桌面的工具拒绝将 headless 记录登记为通过。执行定义或桌面要求变更时，原平台通过证据失效。

相同版本和平台不能更换包摘要，也不能移除已登记包或版本；新增平台可以追加独立包。更新过期签名 URL 前必须重新导入并验证，摘要不符拒绝。普通列表编辑和新登记可以凭已验证摘要及脱敏基址恢复内部完整 URL，避免把隐藏签名覆盖为空。

管理请求以操作者和 `request_id` 为幂等边界，并使用全局修订号防止并发覆盖。上传绑定操作者，按精确偏移接收最大 256 KiB 分块，最多 8 个并行上传且每人最多 2 个，15 分钟无活动后失效。上传分块只保存摘要指纹及偏移回执，不保存 Base64 请求体。

SQLite 和分块写入由阻塞工作线程执行，ZIP 检查与摘要扫描不占异步 reactor；外链文件通过异步文件写入。管理 Future 取消后通过原子标识阻止排队事务继续提交。`execute_authorized` 在提交临界区持有可撤销授权读锁；撤权方取得写锁并撤销后，旧令牌不能再次提交。事务提交后同步更新内存目录并发布精确修订事件；已提交停用不依赖请求 Future 后续是否存活。事件缓冲为 256，消费者遇到滞后应断开相关 Agent，让其以关闭状态重连同步。

## 验证命令与结果

```powershell
cargo test -p remoteops-tool-center --lib
cargo clippy -p remoteops-tool-center --all-targets -- -D warnings
cargo fmt -p remoteops-tool-center -- --check
```

结果：12 项测试全部通过，严格 clippy 和格式检查通过。

| 测试 | 证据 |
| --- | --- |
| 上传、登记、重启和启用分离 | 原始 ZIP 按摘要保存；新工具强制关闭；平台保持 pending；重启恢复开关及目录 |
| 修订号与请求幂等 | 同一请求返回同一回执；跨实例旧修订拒绝；同请求标识不同内容拒绝 |
| 分块与操作者隔离 | 跨操作者上传拒绝；偏移错误、超大分块拒绝；同分块请求不重复写入 |
| 坏 ZIP、摘要和路径 | 损坏目录、摘要不符及 `../` 条目拒绝，均不登记可下载包 |
| 固定版本 | 相同版本平台换摘要拒绝；桌面工具 headless 通过请求拒绝；操作者由服务填写 |
| 签名 URL | 普通快照及 Debug 不含签名；脱敏资料编辑保留实际下载地址 |

| 真实本地 HTTPS 导入 | TLS 测试服务传输 ZIP；403 过期、重定向、错摘要和坏 ZIP 均拒绝；每次结束后临时目录为空 |
| reactor 与取消 | 当前线程运行时中，外部 SQLite 写锁不阻止异步计时；取消等待事务后策略未提交 |
| 修订事件与缓存 | 连续启用、停用、再启用的每个修订独立送达；幂等重放不重复广播；重启加载正确缓存 |
| 撤权与提交 | 请求等待数据库期间撤销授权，随后释放数据库锁，请求返回拒绝且没有修订事件 |
| 测试证据失效 | 修改执行参数后平台恢复 pending，之前的运行测试不继续授予通过状态 |

## 独立集成审查

已向主代理反馈：慢速包导入不得持有全局停用的管理串行门；异步 Relay 不能在状态锁内同步等候 SQLite；目录推送应由已提交事件驱动，避免请求取消丢失停用；撤权与管理提交应共享短授权临界区；MCP 文件摘要循环需要持续限额，上传应核对确认偏移，普通管理入口不应绕开本机 transfer-root 上传流程；连接取消应清理客户端 pending，工具实例跟踪应随停止、断线和会话释放清理。该文档不把代码审查建议等同于整链验收结果。

## 未验证范围

本记录不证明生产 OSS 供应商、代理网络、所有损坏 ZIP 变体、磁盘满及断电恢复、大于 256 个未消费修订的整链处理、真实 1 GiB 网络传输或运行中的 Relay/Agent/MCP 行为已经验收。ZIP 安全校验复用资源运行时的实现；真实 CLI、STDIO MCP、浏览器、后台截图及候选发布验证由对应阶段独立记录。当前服务按一个 Relay 进程持有一个工具中心实例设计；多个独立进程共享同一个数据库时，事务及真实读取可协调，但内存缓存和广播只反映本进程提交，不支持跨进程热更新。
