# Win32 / Slint 0.3.0 对照构建验收

日期：2026-10-31。分支：`codex/windows-native-ui-prototype`。本轮交付是两套独立预览；旧版保留，未替换安装、未提交或推送，未决定正式迁移。

## 改动与交付

提取 `crates/remoteops-agent-desktop-host`，Win32 和 Slint 共用配置、TLS、权限、Agent 生命周期及操作事件桥。Win32 的 `src/product.rs` 仅转换启动参数；新增 `apps/remoteops-agent-slint` 负责 Slint 窗口和绑定，复用原有有界文本模型及剪贴板 worker，不实现另一套 SSH、串口或 Shell 业务。

`scripts/Build-UiComparison.ps1` 用同一 `release-small`、静态 CRT 和路径映射参数构建两版，拒绝覆盖已有交付。各自目录带 Plink 0.83、密码辅助程序及许可；另保留独立 Console 入口。源码快照及锁文件放在 `Corresponding-Source.zip`，逐文件摘要见 `source-files.json`；所有交付文件摘要见 `manifest.json`。

最终交付目录：`artifacts/ui-comparison-0.3.0-20261031/delivery`。复制整个 Win32 或 Slint 目录到现场，使用方法见随包《使用说明》。两 GUI 默认身份、配置和偏好分离；Console 必须显式指定独立配置，不可把其默认行为当作隔离。

真实 GUI 回环包含未知证书取消、仅本次信任不落盘、保存后重启、实际控制码配对、取消及确认完全控制、临时授权不改默认配置、CMD / PowerShell / 持久 Shell、任务完成前首帧、中文与 emoji、stderr、合成密码脱敏、隐藏不停止任务、重新打开同一只读观察窗、万行输出末尾、严格未读清零及正常退出。Slint 未读检查另有 10 项纯逻辑回归，避免非零括号计数被误判为零。

Plink / 传输回环使用本机专用合成 SSH 服务：验证中文、空格和单引号路径、分块上传及远端绝对路径回执、实际文件哈希、密钥核对与轮换拒绝、密码认证、流式 stdout / stderr、exec 拒绝不转交互 Shell、关闭连接取消任务、密码文件 ACL 和清理。它使用 CLI Agent，不等于两版 GUI 的 SSH / 物理串口完整现场验收。

两版主窗口、观察窗和设置页的演示截图均已实际查看。Slint 官方 AboutSlint 的 logo、版本及网址可见，版本文字底部与 Back 按钮顶部无交叠；首次设置中英文往返保持中文草稿。首次及重开不抢焦点检查通过；Slint 重开测试在基线之前明确把自己的主窗置前，随后不再更改前台，报告保留此前置动作，不能扩大为所有第三方前台场景均已实测。

Win32 真实环回最大 tick 为 38ms，最大页面处理 93ms，退出前 pending 为 0，实际控件文本与保留模型一致。Slint 最大应用 timer 工作为 22ms，但不含实际栅格绘制；没有最终模型逐字相等指标，两者不能直接比较渲染性能。Slint 呈现合并间隔约 100ms，Win32 流合并约 33ms，均不是实测帧率。

观察流和显示历史有界。Win32 本次万行突发累计合并了 6,492 条中间显示记录，并有遗漏提示；保留模型追赶成功不等于所有原始输出零丢行。Slint 同样通过共享宿主接收有界观察流。观察窗用于实时观看，尚不能替代完整日志归档。

## 可复核命令

以下命令在本仓库执行。构建、测试临时文件使用 C 盘用户 TEMP，`CARGO_TARGET_DIR` 显式指向 C 盘。`<bin>` 是该 target 的 `release-small`，`<包>` 是本次 delivery，`<新临时目录>` 必须不存在。

```powershell
cargo test --offline --locked -p remoteops-agent-desktop-host -p remoteops-agent-native-prototype -p remoteops-agent-slint
cargo clippy --offline --locked -p remoteops-agent-desktop-host -p remoteops-agent-native-prototype -p remoteops-agent-slint --all-targets -- -D warnings
cargo fmt -p remoteops-agent-desktop-host -p remoteops-agent-native-prototype -p remoteops-agent-slint -- --check
pwsh -NoProfile -STA -File scripts/Test-NativeGuiProduct.ps1 -Executable <包>/Win32/RemoteOps-Win32.exe -ExpectedHash <上述Win32哈希> -OutputDirectory <新临时目录>
pwsh -NoProfile -STA -File scripts/Test-SlintGuiProduct.ps1 -Executable <包>/Slint/RemoteOps-Slint.exe -ExpectedHash <上述Slint哈希> -OutputDirectory <新临时目录>
node scripts/test-native-ui-e2e.mjs --agent <包>/Win32/RemoteOps-Win32.exe --relay <bin>/remoteops-relay.exe --mcp <bin>/remoteops-controller-mcp.exe --ui-client scripts/NativeGui-TestClient.ps1 --clipboard-test scripts/Test-NativeGuiClipboard.ps1 --output <新临时报告.json>
node scripts/test-slint-ui-e2e.mjs --agent <包>/Slint/RemoteOps-Slint.exe --relay <bin>/remoteops-relay.exe --mcp <bin>/remoteops-controller-mcp.exe --ui-client scripts/Test-SlintGuiClient.ps1 --output <新临时报告.json>
node scripts/test-transfer-ssh-e2e.mjs --agent <bin>/remoteops-agent.exe --relay <bin>/remoteops-relay.exe --mcp <bin>/remoteops-controller-mcp.exe --python <Paramiko4.0.0隔离环境>/Scripts/python.exe --askpass <bin>/remoteops-ssh-askpass.exe --plink D:/Tools/putty/PLINK.EXE --native <包>/Slint/RemoteOps-Slint.exe --output <新临时报告.json>
scripts/Build-UiComparison.ps1 -OutputDirectory <全新交付目录>
```

## 失败历史与剩余工作

Slint 首次显示按标题识别观察窗失败，已改用创建时不激活；Stop 失败后错误退出及旧控制码复制反馈已修复并补回归。初次只读观察窗重开测试取到已隐藏窗口作为前台基线，该轮保留为前置条件失败，不改判通过。第一份 release 的 AboutSlint 与 Back 重叠、首次设置缺少语言按钮均已修复；其报告和截图在 `evidence/history` 保留，不能用后续通过覆盖历史失败。

仍未完成：

- 两版在实际现场的控制码连通性、功能和具体 Windows / Server 环境验证，等待用户启动并提供各版控制码。
- 真实交换机和此前特殊 SSH 环境；GUI 中实际 SSH 输出及物理串口完整流程。当前 SSH 为 Plink exec / 无 PTY，不宣称支持仅交互 Shell 的设备。

- Slint 绘制耗时、完整逐字显示一致性、与 Win32 同口径的剪贴板占用压力、第三方前台窗口场景及长时耐久，需要后续补测。
- 完整日志归档、工具资源内嵌／按需下载及最终视觉设计仍是后续工作；正式迁移须结合现场结果再评估。
