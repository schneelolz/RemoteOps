# RemoteOps Relay 管理页面原型设计需求

## 1. 项目目标

为 RemoteOps Relay 设计一个桌面优先的内部运维管理后台，用于查看 Relay、Agent、Controller 和活跃 Session 的状态，并执行会话管理操作。

第一版重点功能：

- 查看 Relay 运行状态
- 查看 Agent 列表与在线状态
- 查看活跃会话和连接中的 Controller
- 查看并复制 Owner UUID
- 查看 Session 详情
- 关闭会话
- 撤销 Controller 绑定
- 紧急停止远程操作
- 查看审计日志
- 管理员登录

当前阶段不需要重点设计 Human Controller Token 管理，也不需要 Agent 输入 Token。Agent 运行时只配置 Relay 地址；AI Controller Token 由 MCP 使用。

## 2. 设计定位

- 产品名称：`RemoteOps Relay Admin`
- 内部运维控制台，不是营销网站
- 桌面端优先，基准尺寸 1440 × 900，同时适配 1024px 宽度
- 默认深色主题，可提供浅色主题
- 专业、稳定、克制、高信息密度，适合长时间监控和重复操作
- 使用中性深灰作为基础色
- 绿色表示在线，灰色表示离线，黄色表示等待或审批，红色仅用于危险操作和严重异常
- 不使用营销式 Hero、大面积渐变、装饰性插画或过度圆润的卡片
- 状态不能只依赖颜色，必须同时显示文字或图标
- Session ID、Agent ID、Owner UUID 等长标识使用等宽字体

## 3. 全局布局

### 左侧导航

固定宽度约 220px，包含：

- 概览
- 会话
- Agent
- 控制器
- Relay 身份
- 审计日志
- 系统设置

当前选中项要有清晰但克制的高亮。

### 顶部栏

显示：

- RemoteOps Relay Admin
- 当前 Relay 名称或地址
- Relay 在线状态
- 最后更新时间
- 刷新按钮
- 当前管理员身份
- 退出登录按钮

## 4. 登录页面

字段：

- Relay 管理地址
- 管理 Token

管理 Token 是后台管理凭据，不是 AI Controller Token、Human Controller Token、Agent 控制码或 Owner UUID。

需要设计初始、显示/隐藏 Token、登录中、登录成功、Token 错误、Relay 不可达和网络错误状态。错误提示不能泄露内部服务信息。

## 5. 概览页面

### 统计指标

顶部显示：

- 在线 Agent
- 活跃会话
- 连接中的 Controller
- 待处理审批

每项包含数值、名称、状态图标和相对上次刷新的变化。

### Relay 状态

显示：

- Relay 状态：Online / Degraded / Offline
- 当前版本
- 启动时间
- 业务端口
- 管理端口
- 当前连接数与最大连接数
- 最后状态更新时间

### 活跃会话

表格字段：

`状态 | Agent | Session ID | Controller 类型 | 权限模式 | 连接时间 | 最后心跳 | 操作`

操作包括查看详情、关闭会话、紧急停止。

### 最近事件

展示 Agent 上线/离线、Controller 连接/断开、Session 创建/关闭、权限变更和紧急停止。

## 6. 会话管理页面

这是后台核心页面。

### 筛选栏

- Session ID 或 Agent 搜索
- 状态筛选
- Controller 类型筛选
- 权限模式筛选
- 时间范围筛选
- 刷新按钮

刷新后保留筛选条件。

### 表格字段

`Session ID | Agent 名称 | Agent ID | Agent 在线状态 | AI Controller | Human Controller | Owner UUID | 权限模式 | 连接时间 | 最后心跳 | 操作`

UUID 和 Session ID 支持复制。表格行点击打开右侧详情抽屉，不跳转新页面。

需要设计：无活跃会话、筛选无结果、Relay 没有 Agent、加载中和 API 请求失败状态。

## 7. Session 详情抽屉

### 基础信息

- 完整 Session ID
- Agent ID、主机名、操作系统
- Agent 能力列表
- Relay 连接状态
- 连接代次
- 创建时间、最后心跳、租约到期时间

### Controller 信息

- AI Controller 是否连接
- Human Controller 是否连接
- Controller Instance ID
- Controller 类型
- Owner UUID
- 绑定时间
- 当前权限模式

### 活动信息

- 待处理审批数量
- 进行中的请求数量
- 最近操作和状态变化

### 危险操作

底部单独分区显示：

- 关闭会话：橙色
- 撤销绑定：橙色或红色
- 紧急停止：红色

## 8. 会话操作流程

### 关闭会话

必须二次确认，并显示 Session ID、Agent、当前 Controller，以及关闭后 Controller 将失去控制权的说明。执行中显示关闭、撤销绑定、清理请求和刷新状态。结果需覆盖成功、失败、Session 已不存在和状态已变化。

### 紧急停止

使用更强的确认弹窗，说明可能终止 Agent 上正在执行的远程操作且不可自动恢复。建议要求输入 `STOP` 后才能确认。设计等待执行、成功、失败、Agent 离线和没有可终止请求状态。

## 9. Agent 管理页面

### 表格字段

`Agent ID | 主机名 | 操作系统 | 在线状态 | Session ID | 控制码状态 | 租约到期时间 | 最后心跳 | 已配对次数`

详情显示 Agent ID、Session ID、主机名、操作系统、能力、权限模式、控制码租约、是否曾经配对、当前 Controller、最近心跳和连接代次。

控制码默认只显示状态和租约，例如：

`控制码已生成，租约剩余 08:42`

不要默认显示完整控制码。

## 10. Relay 身份页面

### Owner UUID

显示完整 UUID、脱敏摘要、复制按钮、当前 Relay 地址，以及说明：Owner UUID 是 Relay 的统一 Controller Owner 身份，AI Controller 和 Human Controller 必须使用同一个值。

### AI Controller Token

只显示是否配置、Token 指纹、创建时间、最近轮换时间、轮换和撤销按钮。不要长期显示完整明文。轮换成功时可在一次性弹窗显示新 Token，提供复制按钮，并提示关闭后无法再次查看，MCP 需要重新配置。

### Human Controller Token

当前阶段显示“未启用”或“暂不管理”，不引入复杂流程。

## 11. 审计日志页面

表格字段：

`时间 | 操作者 | 操作类型 | 目标对象 | 操作结果 | 来源 IP | 详情`

记录登录、登录失败、查看会话、关闭会话、撤销绑定、紧急停止、Token 轮换、Token 撤销和管理配置变更。支持时间范围、操作类型、结果筛选、搜索和导出。

## 12. 必须提供的原型状态

- 登录初始、登录失败、登录中
- 概览正常、Relay 异常
- 没有 Agent、没有活跃 Session、筛选无结果
- Agent 离线、Session 正常
- Session 正在关闭、关闭成功、关闭失败
- 紧急停止确认、成功、失败
- Token 未配置、已配置、轮换成功
- API 加载中、请求失败
- Session 详情抽屉打开
- 复制 UUID 成功

## 13. 交互规范

- 关闭 Session 必须二次确认，紧急停止必须再次确认
- 危险操作使用明确动词，不能使用模糊的“确定”
- 复制按钮点击后显示短暂成功状态
- 危险操作完成后自动刷新相关列表
- 网络操作都要有加载、成功和失败状态，并支持重试
- 关闭详情抽屉不丢失列表位置和筛选条件
- 长 ID 截断显示，悬停或详情中可查看完整值
- 页面不能只依赖颜色表达状态

## 15. 与后续实现的边界

原型只决定页面结构、视觉样式和交互；后续实现会由 Relay 提供独立管理 API 和管理认证。业务 TLS 端口 `7443` 继续用于 Agent/Controller，管理页面使用独立管理端口，默认只监听本机或私有网络。
