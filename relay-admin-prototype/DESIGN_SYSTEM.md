# RemoteOps Relay Admin - 设计系统与规范文档 (Design System & Specification)

本文档是 **RemoteOps Relay Admin** 内部运维管理控制台的原型视觉与交互设计规范。

---

## 1. 设计定位与核心原则

- **产品定位**：高安全等级的内部运维管理控制台（Internal Ops Console），服务于 SRE、运维工程师及自动化系统。
- **设计基调**：**专业、克制、高信息密度、低疲劳度**。坚决摒弃营销式 Hero、大面积渐变、装饰性插画或过度圆润的卡片。
- **三重可访问性（Accessibility）**：**状态决不能仅依赖颜色**，必须同时具备「色彩 + 状态文字 + 状态圆点/图标」的三重语义表达。
- **等宽优先原则**：所有系统长标识（Session ID、Agent ID、Owner UUID、Token 指纹、IP/端口、时间戳）均使用等宽字体显示。

---

## 2. 基础尺寸与布局网格

- **基准分辨率**：`1440px × 900px` 桌面端标准视口。
- **断点适配**：
  - `> 1280px`：4 列统计卡片，双列内容区，宽表格。
  - `1024px ~ 1280px`：2 列统计卡片，横向滚动表格保护。
  - `< 1024px`：全屏滑动抽屉，单列堆叠。
- **固定边栏**：宽度固定为 `220px`，高度 100vh，具备独立滚动区。
- **顶部操作栏**：高度固定为 `54px`，保持全局状态置顶。
- **详情抽屉 (Drawer)**：宽度固定为 `540px`，从屏幕右侧滑入，不丢失当前表格的滚动位置与筛选条件。

## 4. 字体与排版规范

- **常规 UI 字体族**：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`
- **等宽代码字体族**：`"Fira Code", ui-monospace, "SF Mono", "Cascadia Code", Menlo, monospace`
- **字阶系统**：
  - `26px / 700 / Mono`：指标大数字（如 12、38、2）
  - `18px / 600`：页面主标题（H1）
  - `14px / 600`：弹窗标题、抽屉主标题
  - `13px / 600`：表格标题、Relay 节点名
  - `12.5px / 500`：导航项文字、正文说明
  - `12px / 400`：表格正文字段、表单输入框
  - `11px / 500`：表头 TH（大写微间距）、状态标签 Badge、时间戳
  - `10px / 400`：辅助标签、版本标识

## 5. 核心交互组件与安全规范

### 5.1 危险操作二次确认与 STOP 防误触机制
- **关闭会话 (Terminate Session)**：弹出二次确认模态窗，明确展示受影响的目标 Session ID 与 Agent，说明将断开 Controller 控制权。
- **紧急停止 (Emergency Stop)**：最高安全防护。强制要求管理员手动在输入框中输入大写 `STOP` 字符，才能解锁确认按钮，向 Agent 发送紧急停止请求并终止远程操作。

### 5.2 脱敏展示与一键复制 (Copy-to-Clipboard)
- Session ID 与 Owner UUID 默认在表格中进行前缀与后缀截断（例如 `sess-8f3a9b1c...`），悬停可查看完整内容。
- 点击复制组件即刻调用系统剪贴板，并在右下角弹出 2.6s 自动淡出的微提示（Toast Notification），不打断管理员浏览。

### 5.3 AI Controller Token 安全生命周期
- 后台仅展示 SHA-256 指纹与轮换时间，**永不长期展示明文 Token**。
- 轮换 Token 时，弹出一封顶式一次性弹窗（One-time Secret Modal），告知管理员关闭后将无法再次查看明文，并提供一键复制。

## 6. 10 大核心画面交付索引

1. **登录页 (`/login`)**：Relay 管理地址、Token 明密文切换、验证中与错误状态。
2. **概览页 (`/overview`)**：4 大指标卡、Relay 运行状态、端口指标、实时审计流水、活跃会话预览。
3. **会话管理页 (`/sessions`)**：全维度条件筛选栏（关键词/状态/Controller/权限）、高信息密度表格。
4. **Session 详情抽屉 (`Drawer`)**：从右侧平滑滑出，包含 Agent 硬件能力、Controller 拓扑、待审批数与 Danger Zone。
5. **Agent 管理页 (`/agents`)**：Agent 列表、控制码租约安全脱敏（如 `控制码已生成，租约剩余 08:42`）、心跳诊断。
6. **Relay 身份与凭据页 (`/identity`)**：Owner UUID 核心定义、AI Controller Token 状态指纹与轮换。
7. **审计日志页 (`/audit`)**：时间戳、操作者、目标、结果、IP 全链路追溯与 CSV 导出。
8. **关闭会话确认弹窗 (`Terminate Modal`)**：受控关闭与影响范围展示。
9. **紧急停止确认弹窗 (`Emergency Stop Modal`)**：输入 `STOP` 解锁、强制终止提示。
10. **状态与异常矩阵 (`State Matrix`)**：顶部 Ribbon 一键切换正常、降级、离线、空会话、空 Agent、筛选无结果、骨架屏、500 报错。
