# RemoteOps Relay Admin - 设计系统与规范文档 (Design System & Specification)

本文档是 **RemoteOps Relay Admin** 生产管理控制台的视觉与交互设计规范。

---

## 1. 设计定位与核心原则

- **产品定位**：高安全等级的内部运维管理控制台（Internal Ops Console），服务于 SRE、运维工程师及自动化系统。
- **设计基调**：**专业、克制、高信息密度、低疲劳度**。坚决摒弃营销式 Hero、大面积渐变、装饰性插画、悬浮助手或过度圆润的卡片。
- **语言层级**：以中文作为主要标题和字段描述，英文作为次级辅助标注（如 `System Overview`），避免中英文平级争夺视觉重心。
- **三重可访问性（Accessibility）**：**状态决不单纯依赖颜色**，必须同时具备「色彩 + 状态文字 + 状态圆点/图标」的三重语义表达。
- **等宽优先原则**：所有系统长标识（Session ID、Agent ID、Owner UUID、Token 指纹、IP/端口、时间戳）均使用等宽字体显示，并提供防溢出换行与快捷复制机制。

---

## 2. 基础尺寸与布局网格

- **内容容器宽度**：默认 `100%` 流式布局，最大宽度 `1680px` 并保持左侧对齐；避免在 2K/4K 屏幕上把卡片和文本行拉得过长，同时为宽表格保留足够空间。
- **断点适配**：
  - `> 1280px`：4 列统计指标卡片，双列内容区，宽表格自适应铺展。
  - `1024px ~ 1280px`：2 列统计指标卡片，横向滚动表格保护。
  - `<= 1024px`：双列身份与凭据卡片自动折叠为单列堆叠，全屏适配滑动抽屉。
- **固定边栏**：宽度固定为 `220px`，高度 100vh，具备独立滚动区。
- **顶部操作栏**：高度固定为 `54px`，保持全局状态置顶。
- **内容区内边距**：桌面端 `padding: 24px 28px`。
- **卡片圆角**：`6px ~ 8px`（统一定义于 `--radius-md` 与 `--radius-lg`）。
- **详情抽屉 (Drawer)**：宽度固定为 `540px`，从屏幕右侧滑入，不丢失当前表格的滚动位置与筛选条件。

---

## 3. 统一字体阶梯与比例

- **字间距**：全局 `letter-spacing: 0`。
- **行高**：正文基准行高 `1.55`。
- **字阶规范**：
  - **指标大数字**：`28px / 700 / Mono`（如在线 Agent、活跃会话等核心数字）。
  - **页面主标题 (H1)**：`20px / 600`。
  - **页面主说明**：`13.5px / 400`。
  - **区块标题 (Card / Section Title)**：`15px / 600`。
  - **区块副标题 / 辅助英文**：`12.5px / 400`。
  - **正文与说明段落**：`14px / 400`。
  - **字段标签 (Input / KV Label)**：`12.5px ~ 13px / 500`。
  - **等宽标识与表格正文**：`13px / Mono 或 Regular`。
  - **按钮 (Buttons)**：常规 `13px / 500`，紧凑小按钮 `12px / 500`。
  - **状态徽章 (Badges & Tags)**：`12px / 500`。
  - **最小辅助文字**：`12px`（严格杜绝 9px、10px 等过小字号）。

## 5. 核心交互组件与安全规范

### 5.1 危险操作二次确认与 STOP 防误触机制
- **关闭会话 (Terminate Session)**：弹出二次确认模态窗，明确展示受影响的目标 Session ID 与 Agent，说明将断开 Controller 控制权。调用真实后端接口完成操作。
- **紧急停止 (Emergency Stop)**：最高安全防护。强制要求管理员手动在输入框中输入大写 `STOP` 字符，才能解锁确认按钮，向 Agent 发送紧急停止请求并终止远程操作。

### 5.2 脱敏展示与一键复制 (Copy-to-Clipboard)
- Session ID 与 Owner UUID 默认在表格中进行前缀与后缀截断（例如 `sess-8f3a...5001`），悬停可查看完整内容。
- 点击复制组件即刻调用系统剪贴板，并在右下角弹出 2.6s 自动淡出的微提示（Toast Notification），不打断管理员浏览。
- 长指纹与 UUID 提供 `word-break: break-all`，防止在任何分辨率下撑爆卡片布局。

### 5.3 凭据状态与安全说明
- 控制台只展示 Controller 凭据的只读配置状态（已配置/未配置）及 SHA-256 指纹，绝不展示或存储明文密钥。
- 明确标注令牌生命周期由 Relay 启动配置管理，不展示未开放或虚假的轮换/撤销按钮。
