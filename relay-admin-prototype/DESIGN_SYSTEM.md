# RemoteOps Relay Admin - 设计系统与规范文档 (Design System & Specification)

本文档是 **RemoteOps Relay Admin** 内部运维管理控制台的视觉与交互设计规范。

---

## 1. 设计定位与核心原则

- **产品定位**：面向生产环境的高安全等级内部运维管理控制台（Internal Ops Console），服务于 SRE、运维工程师、DevOps 团队及自动化系统。
- **设计基调**：**简洁、现代、美观、克制、高信息密度**。融合现代一流开发者基础设施设计语言（Linear、Vercel、Cloudflare、Raycast 风格），坚决摒弃营销式 Hero、浮夸大渐变、杂乱边框或过度圆润的视觉噪点。
- **语言层级**：以中文作为主要标题和字段描述，英文作为次级辅助标注（如 `System Overview`），字体层级分明，避免中英文平级争夺视觉重心。
- **三重可访问性（Accessibility）**：**状态决不单纯依赖颜色**，必须同时具备「色彩 + 状态文字 + 状态圆点/图标」的三重语义表达。
- **等宽优先原则**：所有系统长标识（Session ID、Agent ID、Owner UUID、Token 指纹、IP/端口、时间戳）均使用等宽字体胶囊显示，提供防溢出换行、悬停提示与点击即刻复制（Checkmark + Toast 双重反馈）。

---

## 2. 基础尺寸与布局网格

- **内容容器宽度**：默认 `100%` 流式布局，最大宽度 `1600px` 并保持居中自适应；在大屏显示器上保护视觉扫描线，同时为多列宽表格提供充分展示空间。
- **断点适配**：
  - `> 1280px`：4 列统计指标卡片，双列身份与凭据卡片，宽表格自适应铺展。
  - `1024px ~ 1280px`：2 列统计指标卡片，横向滚动表格保护。
  - `<= 1024px`：双列卡片自动折叠为单列堆叠，全屏自适应滑动抽屉。
- **固定边栏**：宽度固定为 `236px`，具备独立滚动区与优雅的分组导航。
- **顶部操作栏**：高度固定为 `56px`，带毛玻璃半透明微质感（`backdrop-filter: blur(12px)`），保持全局集群状态、操作与身份置顶。
- **内容区内边距**：桌面端 `padding: 24px 28px`。
- **卡片圆角**：`8px ~ 12px`（统一定义于 `--radius-md` 与 `--radius-lg`）。
- **详情抽屉 (Drawer)**：宽度固定为 `540px`（宽屏）/ 100vw（移动与窄屏），从屏幕右侧滑入，平滑且不丢失当前表格的滚动位置与筛选条件。

## 3. 统一字体阶梯与排版

- **字间距**：全局正文 `letter-spacing: 0`，标题适度紧缩 `-0.3px`，标签字母间距 `+0.5px`。
- **行高**：正文基准行高 `1.5`。
- **字体栈**：
  - **无衬线主字体**：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", sans-serif`
  - **等宽代码字体**：`"SF Mono", ui-monospace, "Cascadia Code", "JetBrains Mono", Menlo, monospace`
- **字阶规范**：
  - **指标大数字**：`28px / 700 / Mono`（核心监控数字，视觉冲击力强且不喧宾夺主）。
  - **页面主标题 (H1)**：`20px / 600`。
  - **页面主说明**：`13px / 400`。
  - **区块标题 (Card / Section Title)**：`14.5px / 600`。
  - **区块副标题 / 辅助英文**：`12px / 400`。
  - **正文与表格正文**：`13px ~ 13.5px / 400`。
  - **字段标签 (Input / KV Label)**：`12.5px / 500`。
  - **等宽标识与代码胶囊**：`12px ~ 12.5px / Mono`。
  - **操作按钮 (Buttons)**：常规 `13px / 500`，紧凑小按钮 `12px / 500`。
  - **状态徽章 (Badges & Tags)**：`11.5px ~ 12px / 500`。

## 5. 核心交互组件规范

### 5.1 实时拓扑链路卡片 (Link Topology)
- 在会话详情抽屉顶部引入结构化拓扑链：`[Controller (MCP / Human)] ── [Relay Gateway] ── [Agent Node]`。
- 节点带有状态发光光环（Active Pulse），连接线以渐变色彩表现传输通路，直观映射分布式拓扑。

### 5.2 危险操作防误触机制 (Danger Safety)
- **关闭会话 (Terminate Session)**：二次确认模态窗，明确说明将切断控制器控制权，记录审计流水。
- **紧急停止 (Emergency Stop)**：最高安全防护。模态窗采用绯红警戒底色与警告提示，强制要求在文本框内手动输入大写 `STOP` 字符方可解锁确认按钮，同时支持回车触发与 `Esc` 取消。

### 5.3 数据胶囊与即时复制反馈 (Micro-Copy Feedback)
- Session ID、Agent ID、Owner UUID、指纹统一封装在代码胶囊内。
- 悬停展示微型复制图标；点击时图标即刻平滑过渡为翠绿对勾（✓）并保持 1.8s，右下角同时弹出全局 Toast 提示。

### 5.4 本地静态模式 (Local Static Mode)
- 页面在本地文件系统（`file://`）打开时自动加载本地数据，不请求 Relay API；通过 Relay 管理地址访问时使用真实管理员认证和管理 API。
- 本地静态模式与生产直连保持相同的页面结构和交互路径。
